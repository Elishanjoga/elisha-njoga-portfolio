# Elisha Njoga Portfolio

A responsive personal portfolio website for Elisha Njoga.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with the preferred public email.
- Replace the LinkedIn and GitHub placeholder links with the actual profiles.
- Add a professional headshot if desired.
- Add links/screenshots for specific public projects.
